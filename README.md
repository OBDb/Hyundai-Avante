# Hyundai Avante

This repository contains signal set configurations for the Hyundai Avante, organized by model year and version. The files are structured to allow for easy differentiation between model generations and other vehicle parameters, ensuring accurate signal mapping for each version of the Hyundai Avante.

The Hyundai Avante is the Korean market name for what is known internationally as the Hyundai Elantra, a compact car produced by Hyundai since 1990. In South Korea, the name "Avante" has been used since the second generation (1995), while export markets continued to use the Elantra nameplate.
